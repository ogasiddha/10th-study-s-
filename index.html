मुख्य साधने व मोड्स

बटण १ (प्रश्न तुमचे, उत्तर आमचे): पाठ्यपुस्तक/सरावातील प्रश्न दिले आहेत; उत्तर तुम्ही लिहा आणि सोडवलेले उत्तर तपासून पडताळा.
बटण २ (१० वी बोर्ड उत्तरपत्रिका): बोर्ड परीक्षेच्या उत्तरपत्रिकेसारखी रचना (प्रश्न क्रमांक, गुण, मार्जिन व ओळी) येथे मिळते.

१० वी बोर्ड परीक्षेची उत्तरपत्रिका (सराव नमुना)
विषय: गणित (भाग १ / भाग २) गुण: ४० बैठक क्र.:
भाग व धडा निवडा
धडा मोड: सोडवलेले प्रश्नोत्तरे
पाठ्यपुस्तकातील महत्त्वाचे मुद्दे (एक ना एक पॉइंट):
    गणित सोडवण्याचा फलक (बोट / पेन्सिल + त्रिकोण व चौकोन)
    प्रमेय व गणित तपासणी — बरोबर/चूक आणि दुरुस्ती (Correction)
    संपूर्ण गणित सूत्रे (बीजगणित व भूमिती)

    बीजगणित — रेषीय व वर्गसमीकरणे

    • सामान्य रूप: ax + by + c = 0

    • क्रेमर नियम: x = Dx / D, y = Dy / D (D ≠ 0)

    • वर्गसमीकरण: ax² + bx + c = 0 (a ≠ 0)

    • विवेचक (Δ) = b² - 4ac

    • सूत्र: x = [-b ± √(b² - 4ac)] / (2a)

    बीजगणित — अंकगणिती श्रेढी व संभाव्यता

    • सामान्य फरक: d = tₙ₊₁ - tₙ

    • n वे पद: tₙ = a + (n - 1)d

    • पहिल्या n पदांची बेरीज: Sₙ = (n/2)[2a + (n - 1)d]

    • संभाव्यता: P(A) = n(A) / n(S)

    भूमिती — त्रिकोण व पायथागोरस

    • त्रिकोणाचे क्षेत्रफळ = (1/2) × पाया × उंची

    • BPT: रेषा एका बाजूला समांतर तर AP/PB = AQ/QC

    • पायथागोरस: कर्ण² = पाया² + उंची²

    • काटकोन त्रिकोणात 30°-60°-90°: 30° समोरील बाजू = (1/2)×कर्ण, 60° समोरील बाजू = (√3/2)×कर्ण

    भूमिती — चौकोन, वर्तुळ व घनफळ

    • चौकोनाच्या कोनांची बेरीज = 360°

    • आयताचे क्षेत्रफळ = लांबी × रुंदी; चौरसाचे क्षेत्रफळ = बाजू²

    • वर्तुळाचा परीघ = 2πr; क्षेत्रफळ = πr²

    • दंडगोल घनफळ = πr²h; शंकू घनफळ = (1/3)πr²h; गोल घनफळ = (4/3)πr³
